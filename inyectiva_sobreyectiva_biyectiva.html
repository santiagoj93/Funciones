∑ Funciones inyectivas, sobreyectivas y biyectivas

GUÍA DE ESTUDIO

Primero, recuerda qué estamos clasificando

Consideramos una función f: A → B. El conjunto A es el dominio y B es el codominio. La imagen está formada por los elementos de B que reciben al menos una flecha.

1. Inyectiva

Elementos distintos del dominio tienen imágenes distintas. Ningún elemento de B recibe flechas desde dos elementos diferentes de A.

Si f(a₁) = f(a₂), entonces a₁ = a₂.

Puede quedar algún elemento de B sin recibir flechas.

2. Sobreyectiva

Todo elemento del codominio B es imagen de al menos un elemento de A. No queda ningún elemento de B sin flecha entrante.

Imagen(f) = B.

Dos o más elementos de A pueden llegar al mismo elemento de B.

3. Biyectiva

Es simultáneamente inyectiva y sobreyectiva. Cada elemento de B recibe exactamente una flecha.

Inyectiva + Sobreyectiva.

Hay correspondencia uno a uno y todos los elementos de B se alcanzan.

Diagramas de ejemplo

Inyectiva, no sobreyectiva

No se repiten imágenes, pero queda un elemento de B sin alcanzar.

Sobreyectiva, no inyectiva

Todos los elementos de B se alcanzan, pero dos entradas comparten imagen.

Biyectiva

Cada elemento de B recibe exactamente una flecha.

¡Cuidado con esta confusión!

Una función siempre debe asignar a cada elemento de A exactamente una imagen en B. La inyectividad y la sobreyectividad son propiedades adicionales: una función puede no tener ninguna de las dos, tener solo una o tener ambas.
